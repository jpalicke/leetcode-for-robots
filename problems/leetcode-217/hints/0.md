# Hint 0: make sure the question is clear

Before you pick a method, check what the function has to hand back.

- It answers a yes-or-no question, so the result is a boolean.
- A repeat means two entries that hold equal numbers. Where they sit in the list does
  not matter.
- Try your own examples by hand: one list with a repeat, one without, and a list with
  a single entry. Say what you would return for each.
