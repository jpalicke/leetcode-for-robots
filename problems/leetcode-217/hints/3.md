# Hint 3: the outline

This level names the technique.

1. Create an empty hash set for the numbers you have seen.
2. Walk through the list once.
3. If the current number is already in the set, return `True`.
4. Otherwise add it to the set and carry on.
5. If the walk finishes, return `False`.

Checking before adding is what stops a number from matching itself. The walk visits
each entry once, so it takes time proportional to the length of the list. Sorting the
list and comparing neighbours also works, at a higher cost.
