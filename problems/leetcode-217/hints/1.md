# Hint 1: one number at a time

Pick any single position `i` and look only at the number there.

- If that number has a twin somewhere else, where in the list could the twin be?
- How would you find out whether it is there, and how many entries would you have to
  examine to be sure?

Now do the same for every position and write down the total work for a list of
100,000 numbers. Is that small enough?
