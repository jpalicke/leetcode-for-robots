# Hint 3: the outline

This level names the technique.

1. Make an empty stack for the opening brackets still open.
2. For each character: if it is an opener, push it.
3. If it is a closer, check that the stack is not empty and that the top is the
   matching opener; if not, return `False`. Otherwise pop it.
4. After the last character, return `True` only if the stack is empty.

A dictionary from each closer to its opener keeps the matching check short. Each
character is handled once, so the work is proportional to the length of the string.
Repeatedly deleting adjacent matching pairs also works, at a higher cost.
