# Hint 0: make sure the question is clear

Before you pick a method, check what the function has to hand back.

- It answers a yes-or-no question, so the result is a boolean.
- A string is valid only if every opening bracket is closed by a bracket of the
  same kind, and the closing happens in a sensible order.
- Try your own strings by hand: one that is valid, one that closes the wrong kind,
  one that closes in the wrong order, and one with a bracket left open. Say what you
  would return for each.
