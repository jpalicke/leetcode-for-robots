# Hint 1: what a closer needs

Pick a closing bracket somewhere in the middle of the string and look only at what
came before it.

- Which earlier opening bracket is the one it is allowed to close?
- Out of all the openers that are still open at that point, which one is that?
- What must be true for the string to be invalid at this exact spot?

Do this for `"([)]"` and for `"([])"` and compare.
