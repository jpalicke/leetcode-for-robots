# Hint 2: a direction

Asking "is this value somewhere in the list?" by scanning the list again for every
position repeats a lot of work. Think about information you could keep as you go, so
that the question "have I already passed the value I need?" is answered right away
instead of by another scan.

Also decide when to record the current number: before you check for its partner, or
after. Try a list with a single `6` and a target of `12` and see which order is safe.
