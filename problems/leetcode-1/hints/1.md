# Hint 1: one number at a time

Pick any single position `i` and look only at the number there.

- If that number is one half of the answer, what exact value would the other half
  have to be?
- Where in the list could you look to find out whether that value is there, and how
  many entries would you have to examine to do it?

Write down what the second question costs for a list of 10,000 numbers.
