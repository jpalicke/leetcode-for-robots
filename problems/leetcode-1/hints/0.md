# Hint 0: make sure the question is clear

Before you pick a method, check what the function has to hand back.

- It returns positions in the list, not the numbers stored there.
- The two positions must be different from each other. Two equal numbers at two
  different positions are fine.
- Try your own example by hand: write a short list and a target, find the pair, and
  say which positions you would return.
