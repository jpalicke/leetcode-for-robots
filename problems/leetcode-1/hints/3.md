# Hint 3: the outline

This level names the technique.

1. Create an empty dictionary that maps a number to the position where you saw it.
2. Walk through the list with its positions.
3. For each number, compute `target - number`.
4. If that value is already a key in the dictionary, return the stored position and
   the current position.
5. Otherwise store the current number with its position and carry on.

Checking before storing is what stops a number from pairing with itself. The walk
visits each entry once, so it takes time proportional to the length of the list.
