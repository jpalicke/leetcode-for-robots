# Hint 3: the outline

This level names the technique.

1. Set `lowest` to the first price and `best` to `0`.
2. For each price in order: if it is below `lowest`, set `lowest` to it.
3. Set `best` to the larger of `best` and `price - lowest`.
4. After the last price, return `best`.

Keeping the lowest price so far and comparing each day to it is a single pass, so the
work is proportional to the number of days. Starting `best` at `0` makes a list that
only falls return `0`. A right-to-left version that tracks the highest price still
ahead works as well.
