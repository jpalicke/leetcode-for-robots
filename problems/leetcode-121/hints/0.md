# Hint 0: make sure the question is clear

Before you pick a method, check what the function has to hand back.

- It returns a profit, a number, not the days you trade on.
- You must buy before you sell. A big drop after a high price does not help you.
- When there is no profitable trade, the answer is `0`, not a negative number.
- Try your own lists by hand: one that only rises, one that only falls, one where the
  lowest price comes late, and a list with a single day. Say what you would return
  for each.
