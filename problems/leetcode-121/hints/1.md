# Hint 1: fix the day you sell

Pick any one day and pretend it is your selling day.

- Which earlier day would be the best one to have bought on?
- How would you find it, and how many days would you have to look at?
- If you did that for every possible selling day, how much work is it for a list of
  100,000 days?

Write the work down. Then ask what you already know about the earlier days when you
reach each new selling day.
