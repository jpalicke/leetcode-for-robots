# Hint 0: make sure the question is clear

Before you pick a method, check what the function has to hand back.

- It returns a position in the list, not the number stored there.
- If the number is absent, the answer is `-1`.
- The list is sorted and its values are all different, and the problem asks for much
  better than looking at every entry.
- Try your own lists by hand: a target near the front, one near the back, one that is
  missing, and a list with a single entry. Say what you would return for each.
