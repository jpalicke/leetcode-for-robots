# Hint 3: the outline

This level names the technique.

1. Set `left = 0` and `right = len(nums) - 1`.
2. While `left <= right`, take `mid = left + (right - left) // 2`.
3. If `nums[mid] == target`, return `mid`.
4. If `nums[mid] < target`, set `left = mid + 1`. Otherwise set `right = mid - 1`.
5. When the loop ends, return `-1`.

This is binary search. Each step cuts the remaining part about in half, so it takes
about `log2(n)` steps. Always moving past `mid` is what guarantees the loop stops.
