# Hint 1: what has to match

Pick one letter, say `e`, and look at both strings.

- If `t` is an anagram of `s`, what must be true about how many times `e` shows up
  in each?
- Does the same hold for every other letter?
- If the two strings have different lengths, can you already say something?

Write down the shortest list of facts that, if all true, would make the answer `True`.
