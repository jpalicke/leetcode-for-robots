# Hint 2: a direction

You could compare the strings letter by letter, but their order is allowed to
differ, so position by position will not work. Think of a way to make the order stop
mattering: either put both strings into one agreed order first, or keep a running
record of how many of each letter you have met so far, and compare those records at
the end (or adjust one record while reading the other string).

Decide which of the two you would trust more, and what each would cost for 50,000
letters.
