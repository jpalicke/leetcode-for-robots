# Hint 0: make sure the question is clear

Before you pick a method, check what the function has to hand back.

- It answers a yes-or-no question, so the result is a boolean.
- An anagram uses the same letters the same number of times. Where the letters sit
  does not matter.
- Try your own pairs by hand: one that is an anagram, one with a single wrong letter,
  one with the same letters but different amounts, and one with different lengths.
  Say what you would return for each.
