# Hint 3: the outline

This level names the technique.

1. If the lengths differ, return `False`.
2. Make a table of 26 counts, one for each letter, all starting at zero.
3. For each letter of `s`, add one to its count. For each letter of `t`, subtract one.
4. If every count is zero at the end, return `True`; otherwise return `False`.

A shorter alternative is to sort both strings and compare them. It is simpler, and a
little slower for long strings.
